# Home and threads

**What's here:** how the web chat's Home works, what a thread is, and how to follow and open one.

Your household may have threads turned on. If the web chat opens on a page titled **Home**, they
are; otherwise the chat works as a list of separate conversations, described in
[interfaces.md](interfaces.md).

## Home

Home is one ongoing conversation with the assistant, and it is where the web chat opens. Ask quick
questions, make small changes, and set reminders there, the way you would message someone you talk
to every day. You don't need to pick a conversation or start a new one first.

Home always uses the main assistant, so the profile picker is locked while you are in it.

## Threads

Some jobs outlive a single reply: they run in the background, wait on someone, take several steps
you'll want to follow, or are a project you'll come back to. For those, the assistant starts a
**thread** and says so in its reply. You can ask for one too, for example *"Start a thread to find
three plumbers and get quotes."*

A thread is handled by whichever kind of assistant suits the job, such as research or browsing, and
it keeps that choice for as long as it runs.

### Following a thread from Home

Where the assistant started a thread, Home shows a card for it. The card keeps itself up to date
rather than adding a message for every step. It shows:

- a coloured dot for where the thread stands: **Working** (amber), **Waiting on you** (purple), or
  **Failed** (red)
- the thread's title, and which assistant is running it
- the thread's latest message, such as a question it needs you to answer

Click the card to open the thread.

### Inside a thread

An open thread is an ordinary chat: read what the assistant has done, answer its questions, and ask
for more. The bar above it shows:

- **← Home**, which takes you back to Home
- what the assistant asked the thread to do when it started it
- **Working…** while the thread is busy

The thread's assistant is fixed, so the profile picker is locked here too.

## The sidebar

The sidebar lists **Home** first, then your threads grouped as **Waiting on you**, **Working**, and
**Failed**, so whatever needs you is at the top. Conversations from before threads, and any you
start with the new-chat button, are listed under **Earlier**. Searching looks through all of them.
